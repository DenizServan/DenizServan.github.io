# denizservan.github.io

Projects by Deniz Servan Kazak — hardware, software and control.

A single static page (`index.html`) with no build step. The illustrations are inline SVG.

## Publish on GitHub Pages

1. Create a **public** repository named exactly `DenizServan.github.io`.
2. Upload these files to the repository root (or `git push` them).
3. Go to **Settings → Pages → Build and deployment**, set Source to **Deploy from a branch** and pick `main` / `(root)`.
4. After a minute or two the site is live at https://denizservan.github.io

## Folders

| Path | What goes there |
|---|---|
| `assets/img/greenhouse/` | PCB photos for the greenhouse project. Uncomment the photo block under the greenhouse project in `index.html` |

Keep photos around 1600 px wide (JPEG or WebP). GitHub rejects files over 100 MB, and Pages does not serve Git LFS files.
